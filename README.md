# Pointer Difference in an Array

## Description
This program demonstrates pointer subtraction in an array.

When two pointers point to elements of the same array, subtracting one pointer
from the other gives the number of array elements between them.

## Concepts Used
- Pointers
- Array
- Pointer arithmetic
- Pointer subtraction
- Dereference operator

## Sample Output
Value at start pointer = 20
Value at end pointer = 50
Number of elements between pointers = 3
